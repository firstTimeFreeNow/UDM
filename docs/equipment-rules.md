# 強化・費用ルール

## 1. 装備データ

通常装備はLv310以上を対象とし、アクィルス・インファーナルは追加指定の系列としてLv300も含める。エフェクト装備は、強化上限255以上であればLv310未満も選択候補に含める。

資料に未掲載の装備上限・固定手数料は未確認値として保持し、入力画面で補完できるようにする。アクィルスのビアヌ費用は武器10,500,000、防具11,250,000、AF9,000,000 SEEDを使う。

装備ごとに部位、装備条件レベル、装備可能キャラ、MR範囲、エンチャント後の上限、初期合成回数、操作の適用可否、固定手数料を保持する。同名の能力別バリエーションは別IDで管理する。

現在の実数値とMR範囲、エンチャント後の上限を区別する。強化で増やせる値は現在値と上限の差であり、上限値そのものを加算しない。マジックアーマーは装備種類だけで一律に除外せず、個別の適用条件で判定する。封印装備等の操作禁止を優先する。

## 2. インクリ

対象はビアヌとエタ。成功時は合成回数を1減らし、インクリ回数を1増やす。能力値は直接増加しない。合成回数1/4まで使用可能とする。

エタはエタレベルの装備条件がある装備を対象とする。適用可否と費用は装備単位で管理する。両方式を使える装備では方式を選択可能にする。

### エタ

計算用成功率は1%。1試行につき呪文書1枚と手数料を消費する。

| 装備系列 | 通常の試行手数料 |
| --- | ---: |
| セイクリッド | 296,680,000 SEED |
| 改・セイクリッド | 313,680,000 SEED |

エタインクリ呪文書の固定購入費用は1枚200,000,000 SEEDまたは30,000 ELSO。試行手数料と呪文書購入費を分ける。

## 3. エンチャント

成功時に能力値と合成回数を更新する。能力値は装備上限までで切り捨てる。アビリティ等の任意加算は上限とは別枠で加算する。通常の呪文書は成功時のみ消費し、使い捨て呪文書は毎試行消費する。エンチャント手数料は計上しない。

比較候補は刺突・斬撃・魔力・抗魔の＋14／＋17／＋20と、ELSO商店の使い捨て呪文書とする。＋10は比較対象外。商品単位で使用候補から除外できる。通常強化は＋14／＋17／＋20を使い、使い捨ては部位ごとに明示したすぐ乗り換える予定の装備か、装備本来の強化上限までの残りをその1回の成功で埋める調整に限る。上限外のアビリティ補正を差し引いた残り枠で判定する。ELSO優先の支払いと使い捨ての使用可否は別に扱う。

### 費用見積りの計算モデル

祝福値の入力・蓄積・リセットは計算しない。通常の対象呪文書は固定10%、ELSO使い捨て＋12は固定2%を見積りの基準値とする。これらは簡易モデルの確率であり、実際の祝福値を含む成功挙動の再現値ではない。使用した確率と計算ルールのバージョンを結果へ対応付ける。

## 4. 通貨・割引・在庫

- ELSOとSEEDは別残高で保持し、ELSO対応の操作・商品の支払いでのみ代替可能とする。
- ELSO対応手数料の基準比率は1 ELSO＝10,000 SEEDの2/3。最低費用、割引、端数処理は操作別に定義する。
- 20%割引オンでは対象手数料を通常額の80%とする。呪文書の購入単価、素材数、成功率は割り引かない。
- 所持品は任意入力、未入力は0。追加購入に使う前に在庫を消費する。
- 同じ商品を複数部位で使う場合も在庫を共用し、二重使用しない。
- 使い捨て商品は、失敗による消費と途中での在庫枯渇を費用分布へ反映する。

## 5. テシスコア

入力・育成計算を有効にした場合だけ扱う。地域ごとに装着位置1〜6、能力タイプ、進化段階0〜4、強化段階0〜4を管理する。強化4から次の進化・強化0への遷移を区別する。

各遷移に、到達後の補正、試行素材、手数料、地域別成功率を対応付ける。エクリプス・ルビコナにマーキュリアル洞窟・アビス用の成功率を適用しない。

通常試行の素材・手数料と、所持する強化進化券による試行を区別する。同じ試行へ券と通常費用を二重計上しない。券は対象地域と利用可能段階を制限する。

必要素材数を強化手順に表示し、素材収集の期間は資金ロードマップへ加えない。入力された現在状態を起点とし、コア本体・箱のランダム入手を自動的に費用へ追加しない。

## 6. レリック・カフス

現在値と育成による能力値の増分、段階別上限、固有条件を扱う。育成費用、素材消費、育成期間の詳細計算は行わない。

神鳥ペンダントからルナリアペンダント、神鳥ブレスレットからルナリアブレスレットは、それぞれ同一部位の系列進化とする。現在値を最大値へ自動置換しない。

## 7. 確率と予算

成功確率pが一定の単一操作を成功まで繰り返す場合、次を使用する。

- 期待試行回数：`1 / p`
- n回以内の成功確率：`1 − (1 − p)^n`
- 成功確率qに必要な試行回数：`ceil(log(1 − q) / log(1 − p))`

p＝1は1回とする。成功率不明・0・範囲外の値を有効な確率として計算しない。

計画全体の期待費用・90%予算・95%予算は、各手順の費用分布から求める。各操作の95%金額を単純加算して計画全体の95%予算にしない。成功時のみ消費する商品の購入代は、試行手数料と分けて計算する。

予算は計算モデルに基づく目安として表示する。所定の予算で必ず成功するとは表示しない。

カフスは神秘鉱系アビリティを2枠、ルナリアレリックは右・左それぞれ専用アビリティを1枠入力する。右は安息系の能力値補正、左は不死系の命中・回避・クリティカル・HP補正を扱う。能力値補正は本体の強化値と別に加算し、カフス本体の入場条件判定へアビリティを混ぜない。神鳥ではアビリティ補正を適用しない。
