# キャラクター・戦闘タイプと主能力値

戦闘タイプは、条件判定と強化提案に使う主力攻撃の系統とする。キャラクター作成時のタイプや、スキル習得時の自動上昇ステータスとは分けて扱う。

S＝STAB、H＝HACK、I＝INT、M＝魔法防御力MR。表中の名称を戦闘タイプの選択肢として使用する。

| キャラクター | 戦闘タイプ → 主能力値 |
| --- | --- |
| ルシアン | 突き → S／斬り → H／物理複合 → S+H |
| ボリス | 斬り → H／物理複合 → S+H／魔剣 → H+I |
| ティチエル | 攻撃魔法 → I／補助魔法 → M／打撃 → S+H |
| ミラ | 斬り → H／物理複合 → S+H |
| イスピン | 突き → S／斬り → H／物理複合 → S+H |
| マキシミン | 斬り → H／物理複合 → S+H／魔剣 → H+I |
| ナヤトレイ | 突き → S／斬り → H／物理複合 → S+H |
| シベリン | 突き → S／物理複合 → S+H |
| ジョシュア | 剣闘士 → S／魔法師 → I |

## 選択と判定

- キャラクターに対応する戦闘タイプだけを表示する。一つの場合は自動選択する。
- 同じ主能力値を使用する属性違いは分けない。
- 基本攻撃・補助スキルの依存値だけから、戦闘タイプを追加しない。
- アナイスの魔法人形は本人のINTを基準にする。召喚獣のSTABを本人装備のSTABとして扱わない。
- S＋H、H＋Iは対応する2能力の合計で条件判定し、強化先は部位の上限・呪文書・費用を比較して選ぶ。
- ランジエの補助スキルにあるS＋I依存は、独立した戦闘タイプとして登録しない。
- ダメージ計算の倍率を入場条件へ掛けない。サブスキルを含むダメージ全体の最適化は行わない。
