# 強化計画と資金ロードマップの計算例

以下の装備状態・収入は計算例の入力値。呪文書価格は[初期価格](equipment-rules.md)を使用する。期待費用と確率別予算は、記載した固定成功率のモデルで計算する。

## 1. エンチャントのみ

### 入力と手順

| 項目 | 値 |
| --- | --- |
| キャラ・戦闘タイプ | クロエ・攻撃魔法（INT） |
| 目標 | 色を失った大地、INT2,200、コア条件なし |
| 現在の装備合計INT | 2,186 |
| 武器 | アビス武器、合成3/4、INT上限まで14以上の余地あり |
| 使用呪文書 | 魔力＋14、所持0、1枚60億SEED |
| 手数料割引 | 20%オン |
| 初期資金・ELSO収入 | 0 |
| 毎週のSEED収入・上限・予算 | 各25億 |

空き1枠へ魔力＋14を1回成功させ、装備合計INTを2,200にする。インクリは不要。既存エンチャントは現在値へ含め、再加算しない。

### 費用

エンチャント成功率は固定10%。呪文書は成功時のみ消費し、エンチャント手数料は計上しない。

| 内訳 | 期待費用 |
| --- | ---: |
| 呪文書1枚 | 60億SEED |
| 合計 | 6,000,000,000 SEED（60億） |
| 95%予算：呪文書1枚 | 6,000,000,000 SEED（60億） |

### 資金見通し

| 週 | 通常収入のみ | 2週目に20億SEEDの臨時収入あり |
| --- | --- | --- |
| 0 | 0 | 0 |
| 1 | 25億 | 25億 |
| 2 | 50億：不足 | 70億：予算を賄える |
| 3 | 75億：予算を賄える | ― |

期待費用・95%予算のいずれも、通常収入のみなら3週、臨時収入ありなら2週で賄える。

## 2. インクリからエンチャント

### 入力

| 項目 | 値 |
| --- | --- |
| キャラ・戦闘タイプ | ルシアン・突き（STAB） |
| 目標 | 色を失った大地、STAB2,200、コア条件なし |
| 現在の装備合計STAB | 2,186 |
| 武器 | アビスレイピア、現在STAB358、上限400 |
| 現在STABの内訳 | 素の330＋既存エンチャント28 |
| 合成回数・インクリ回数 | 4/4、インクリ0回 |
| 使用呪文書 | 刺突＋14、所持0、1枚30億SEED |
| 手数料割引 | 20%オン |
| 初期資金・ELSO収入 | 0 |
| 毎週のSEED収入・上限・予算 | 各25億 |

### 強化手順

| 手順 | 操作 | 合成回数 | インクリ回数 | 武器STAB | 装備合計STAB |
| --- | --- | --- | --- | ---: | ---: |
| 現在 | ― | 4/4 | 0 | 358 | 2,186 |
| 1 | ビアヌを1回成功させる | 3/4 | 1 | 358 | 2,186 |
| 2 | 刺突＋14を1回成功させる | 4/4 | 1 | 372 | 2,200 |

インクリは合成枠を空ける操作であり、能力値を直接増やさない。武器STAB372は上限400以下。現在装備の強化で届くため装備更新は提案しない。

### 費用

ビアヌ成功率0.070%、エンチャント成功率10%で計算する。

| 内訳 | 計算 | 期待費用 |
| --- | --- | ---: |
| ビアヌ1成功 | 11,325,000×0.8÷0.0007 | 約129.43億SEED |
| 刺突＋14 | 1枚×30億 | 30億SEED |
| 合計 | 上記2項目 | 約159.43億SEED |

ビアヌは毎試行9,060,000 SEEDを消費する。必要なインクリ成功は1回。追加のインクリ成功を目指す場合は成功率を次の回数へ切り替える。

| 計画全体の指標 | 予算 |
| --- | ---: |
| 期待費用 | 約159.43億SEED |
| 90%予算 | 32,798,340,000 SEED（約327.98億） |
| 95%予算 | 41,767,740,000 SEED（約417.68億） |

90%・95%予算はインクリの試行費用の分布と呪文書購入費から求める。

### 資金見通し

| 予算 | 通常収入のみ | 2週目に20億SEEDの臨時収入あり |
| --- | ---: | ---: |
| 期待費用 | 7週目（175億） | 6週目（170億） |
| 90%予算 | 14週目（350億） | 13週目（345億） |
| 95%予算 | 17週目（425億） | 16週目（420億） |

週数は各予算を賄うまでの目安。強化の成功週を保証するものではない。

### ELSOがある場合

初期ELSO50万、当週の追加獲得余地なし、SEED資金ありの場合、ビアヌ1試行に1,359 ELSOを優先使用する。

- 367試行すべて失敗した場合のELSO支出は498,753、残高は1,247。
- 次の試行はELSO残高が不足するため、9,060,000 SEEDで支払う。
- 途中で成功すればインクリを止める。
- 刺突＋14の市場購入代30億SEEDはELSO払いに置き換えない。

ELSOがある場合の合計費用・週数は支払配分から再計算する。

## 3. コア育成

クロエ・攻撃魔法でアフェティリア（ハード）を目標とし、本人の装備条件は達成済みとする。エクリプスの魔法攻撃型コア6枠を入力する。

| 装着位置 | 段階 | 1枠の補正 | 枠数 | 小計 |
| --- | --- | ---: | ---: | ---: |
| 1〜5 | 進化2・強化4 | 20 | 5 | 100 |
| 6 | 進化2・強化3 | 18 | 1 | 18 |
| 合計 | ― | ― | 6 | 118 |

必要120に対して2不足。位置6を進化2・強化4へ強化し、18→20にすると合計120となる。コア補正は本人の装備値へ再加算しない。

この操作の1試行は粉140、11,500,000 SEED、成功率5%。割引オフ、ELSOなし、券なしで、失敗時の段階を維持して成功まで繰り返す計算モデルでは、期待試行20回、期待粉2,800、期待手数料230,000,000 SEEDとなる。

コア入力を有効にした場合のみ手順・費用を表示する。素材の収集期間は計算しない。
